# Insurance Enrollment Prediction & Outreach Assistant

An end-to-end ML system that predicts whether an employee will opt in to a new voluntary insurance product, and a small tool-using **Outreach Assistant** agent that ranks employees for a benefits team's limited outreach budget — with explicit, enforced refusal rules against target leakage and protected-attribute justification.

Built for the Froncort.AI ML Intern Assignment. See [`report.md`](report.md) for the full write-up (data issues, leakage/fairness reasoning, model evaluation, agent design) and [`AI_USAGE.md`](AI_USAGE.md) for AI tool usage disclosure.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running the pipeline (in order)

```bash
# 1. Clean the raw data, engineer features, resolve duplicates/sentinels
python src/data_processing.py

# 2. Stratified 80/20 split (excludes leaky + demographic features)
python src/train_test_split.py

# 3. Train, cross-validate, evaluate, run the fairness audit, save the model
python src/model_training_and_evaluation.py
```

This regenerates `data/processed/*.csv` and `models/enrollment_model.joblib` from scratch. Final reported metrics: **ROC-AUC 0.9682, accuracy 92.4%** on a held-out test set, trained without `legacy_propensity_score` (confirmed target leakage) or `age`/`gender`/`marital_status` (excluded on fairness grounds — see `report.md` §2).

## Using the agent (CLI)

```bash
# 1. Rank top outreach candidates in a region, capped at that region's HR outreach capacity
python src/cli.py rank --region Northeast --capacity

# 2. Predict enrollment probability for a specific employee
python src/cli.py predict 17825

# 3. Explain a prediction in plain language (never cites gender/marital_status/age)
python src/cli.py explain 17825

# 4. Region profile lookup
python src/cli.py rank --region Midwest --top_k 1   # or see the "Region Profile" tab in the dashboard

# 5. Refusal demo — requesting the excluded leaky feature is explicitly refused
python src/cli.py predict 17825 --feature legacy_propensity_score
```

Each command prints structured JSON. Refusals return `{"status": "refusal", "refusal_type": "TARGET_LEAKAGE_REFUSAL", ...}` rather than silently dropping the request.

## Key design decisions (details in `report.md`)

- **Duplicate `employee_id` rows** (8 pairs, conflicting `enrolled` labels): both rows dropped for each pair.
- **`legacy_propensity_score`**: excluded — 0.976 correlation with the target, 1.0000 AUC on its own. Refused by the agent if explicitly requested.
- **`age`, `gender`, `marital_status`**: excluded from model training on fairness grounds (measured cost: 1.0000 → 0.9682 AUC). Retained in the raw dataset for post-modeling subgroup auditing only.
- **`prior_year_enrolled` sentinel** (`-1` = no prior-year record): split into two independent binary flags rather than treated as a literal 0/1/-1 numeric feature.
